目標：公立幼兒園正式教師
  1. 在幼兒園當專任、月薪的教保員，累積滿 3 年（托嬰中心、助理教保員、時薪、兼職都不算）
  2. 報名幼教專班（約 18 學分），修完拿到修畢證明
  3. 考教師資格考試（教檢）
  4. 教育實習半年（近 7 年實際教學滿 3 年、表現優良可申請免修）
  5. 考新北市（或其他縣市）幼兒園教師甄選 → 正式教師

排序：公立 非營利 準公共 優先，年資最穩、也最接近公幼環境。代理／代課 要問清楚是否專任月薪、做完能否續聘，免得 3 年年資中斷。實際規定請以師培大學與教育部公告為準。
